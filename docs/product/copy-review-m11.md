# 界面文案改写对照（M11，2026-09-23）

维护者反馈：界面文字太工程师化。本表列出各页面主要文字的「改前 → 改后」，供维护者评审。技术细节（路径、版本、扫描数、原始错误）默认收进「详情」折叠。


| 页面 | 改前 | 改后 |
| --- | --- | --- |
| 侧栏·管理 | 派发框架 | 派活关系 |
| 任务看板·顶部 | 无说明；「Codex app-server：已连接/未连接」 | 「任务看板 / 这里显示各个 Agent 正在做什么。点一条任务，可以把它所在的窗口调到前台。」连接状态收进详情 |
| 任务看板·行 | 直接显示 session id、token、sub 数；「等输入/压缩上下文/限流」 | 只留 Agent、标题、状态（等待你输入/整理上下文/额度用尽，等待恢复）与耗时；细节进「详情」 |
| 使用额度·顶部 | 「Usage / Remaining quota and local token usage per provider…」 | 「使用额度 / 看看每个工具还能用多少、最近用掉了多少。这里只做统计，不改动任何东西。」 |
| 使用额度·表格 | Provider / 来源 / 新鲜度 / Connected / Waiting for data | 工具 / 更新时间 / 已获取 / 正在查询；来源与原始说明进「详情」 |
