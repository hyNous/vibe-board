Understand Vibe Board

Vibe Board is a desktop board that watches without operating: it surfaces your local Agents' task state, remaining quota, and local usage cost in a floating island. This tutorial explains, in four themes, what it does and what it never does.

1Using the island

The island sits at the top of the screen by default and can also be dragged to the left or right edge. It has two main shapes: a small pill when collapsed, a panel when you hover or click it.

Claude Code
CodexFix the login flow
Claude CodeRun the tests

Collapsed → hover to expand → move away to collapse. An illustration; the real shape follows your appearance settings.

  • Expand and collapse: hovering the pill expands it, moving away collapses it, and Esc steps back one level (expanded → hover → collapsed). Pressing Esc again while collapsed keeps it quiet for 30 seconds, so ordinary notifications no longer wake it.
  • Global shortcuts: Ctrl/Cmd+Shift+I toggles the panel and Ctrl/Cmd+, opens Settings by default. Both can be rebound in Settings → Shortcuts, where expand, collapse, and previous/next session can get their own keys too.
  • Docking: it sits centered at the top of the screen by default; horizontal dragging is on by default, so dragging the pill to the left or right edge docks it there as a vertical pill. Position, horizontal offset, and vertical offset are all adjustable in Settings → Appearance.
  • Multiple monitors: it follows the monitor under your cursor by default; Settings → Appearance can pin it to one screen instead.

2What the board shows

The expanded panel lists current sessions, sorted by priority: errors and waiting sessions first, then working ones, then completed or interrupted sessions.

Codex Fix the login flow Working...
Gemini CLI Add unit tests Task complete

Each task card: status dot, Agent name, session title, status text. An illustration.

  • Session states: working, waiting for input, blocked, rate limited, error, task complete, interrupted. The board only mirrors what the Agent reports; it never judges on its own.
  • Top counters: ALL / ACT / WAIT count total, running, and waiting sessions. When quota display is on, this row shows the remaining-quota bar instead.
  • Hook health indicator: it appears in the top-right only when the self-check finds a problem (triangle icon plus the failing count), and stays hidden when everything passes. Open it to see each check result and reinstall hooks with one click.
  • The bottom carries the brand and slogan; when a new version is detected, an update notice appears in the panel.

3What a task click does

Clicking a task card does exactly one thing: it takes you back to where that session actually lives. The board never replies, approves, or executes anything for you.

Codex
Fix the login flow · Working...
➤ →
Open the CLI manually to view progress

Desktop Agents are brought back to the front; CLI-only sessions have no window to raise, so the island just shows a hint.

  • Desktop Agents (for example Codex Desktop, or a session with a desktop window): clicking the task brings the app window hosting that session to the front.
  • CLI-only sessions: there is no window to raise, so the board says “Open the CLI manually to view progress”.
  • Pressing Ctrl/Cmd+J while the island is focused jumps straight to the active session's terminal window.
  • The board only watches: there is no way to approve, answer, or chat with an Agent from it.

4Connecting Agents

The setup wizard appears the first time you open the app: it detects the Agents installed on this machine, lets you pick which ones to connect, then installs local hooks for them.

Claude Code Codex Gemini CLI Island

Hooks only forward events to the board; the board never replies, and the Agent never waits for it.

  • Only Agents with a runnable CLI can be connected; ones with just a config directory are shown with a prompt to install the CLI first.
  • Each Agent has a “Start Vibe Board on session start” switch that is off by default. When on, the board tries to come up as that Agent starts a session; desktop Agents may not emit session-start events, so the switch may have no effect for them.
  • The wizard only changes the Agent configurations you confirm: it uploads no credentials, prompts, or project files, and it neither installs nor upgrades Agents.
  • To redo it later: reopen the wizard from Settings → System → Tutorial & Wizard, and reinstall hooks with one click from the island's health indicator when something fails.
No Agent installed yet? Install the CLI, fully quit and reopen Vibe Board, then run detection again in the wizard.

5Skill management

Manage → Skill shows user-level Skills and which Agents each one applies to. A Skill in the center library applies to no Agent by default; it takes effect only after you install it into an Agent.

CustomImported or hand-written locally GitHubRemote updates can be checked Synced from AgentAdopted from an Agent directory
opencode-agent → Claude Code
opencode-agent → Codex

Three source categories; “applies to” is a real install relationship, not an exclusive binding.

  • Grouped by source: Custom (local folders, archives, manual center imports), GitHub (remote repositories recorded in the source lock file), and Synced from Agent (adopted from an Agent's Skill directory).
  • GitHub sources can check for updates: the difference between remote and center library is previewed first, and only a confirmation overwrites the center copy. Local sources have no remote update check.
  • Only user-level Skills are counted; project-level .skills directories are not scanned. Problems such as broken links show up as notices on the Skill library page.

6Usage & quota

Run → Usage has two blocks: “Now” for remaining quota, and “Usage & Cost” for tokens and estimated cost settled from local logs.

Now Remaining Resets Source Freshness
Provider Today / Week / Month Tokens Estimated cost Codex Today 128.4k Estimated $1.92 Claude Code This week 42.0k — (no public price, tokens only)

Numbers are illustrative; quota, tokens, or prices that cannot be read show Unknown instead of 0.

  • “Now”: each provider's remaining quota, reset time, source, and freshness, with a status of connected, needs authorization, disabled, failed, or not integrated.
  • “Usage & Cost”: today / this week / this month, listing input, output, cache read, cache write, and request counts per provider and model; opening the page scans local session logs in the background.
  • Costs are always Estimated equivalent costs, for reference only, derived from the built-in table of published vendor prices, which carries an effective date; models without a public price show token usage only, with no amount. Daily totals are persisted, so history stays queryable even after the Agent cleans up raw logs.
  • Usage has two layers. The “Show quota on the island” master switch only controls the island header. Online queries are all off by default: authorize each provider on the page, where Vibe Board first explains which address it will call, or which local program it will run, and which local credential file it reads (file location only, never the value). The query starts only after you confirm, and you can revoke it at any time. “Open official login” only opens a terminal for the provider's own login and is separate from online authorization. Local session logs and local files need no authorization and keep working. Anything unreadable stays Unknown.

7Dispatch framework (brief)

Manage → Dispatch framework offers a setup wizard: detect → preview → confirm, installing four dispatch Skills into the user-level Skill directories of Claude Code and Codex.

external-agent-core external-agent-setup opencode-agent antigravity-agent

The wizard only installs Skills; it lists the files to be written before anything is written.

  • Dispatch rules stay yours: the wizard never writes your global instruction files (such as CLAUDE.md or AGENTS.md), and when or to whom to dispatch is yours to decide.
  • Other CLI tools: the wizard offers no configuration form; run external-agent-setup inside your Agent to generate a named Skill.
  • Dispatching never goes through Vibe Board: once the Skills are installed, your main Agent dispatches directly, and the board just watches.
