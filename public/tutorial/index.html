GUIDE

Follow the settings, block by block

Vibe Board is a desktop board that watches without operating: it surfaces your Agents' task state, remaining quota, and local usage in a floating island. This tutorial walks through the settings in order, block by block, explaining what each feature is and how to use it.

1Using the island

The island sits at the top of the screen by default and is the one place you operate directly. Collapsed it is a small pill; hover or click it and it expands. The most common actions all live here.

Claude Code
CodexFix the login flow
Claude CodeRun the tests

Collapsed → hover to expand → move away to collapse. An illustration; the real look follows your Appearance settings.

  • Expand and collapse: hover the pill to expand, move away to collapse. Esc steps back one level (expanded → hover → collapsed). Press Esc once more while collapsed and it stays quiet for 30 seconds, ignoring ordinary notifications.
  • Clicking a task: it brings the window hosting that session to the front. A command-line-only session has no window, so the island tells you to check its terminal.
  • Common shortcuts: Ctrl/Cmd+Shift+I shows or hides the island, Ctrl/Cmd+, opens Settings, and Ctrl/Cmd+J jumps to the active task's terminal window.
  • Notification check: normally nothing shows in the top-right corner. Only when the event-notification check finds a problem does a warning icon appear; open it to see each result and use “Reconnect” so Agents report status to the board again.
  • Docking: it sits centered at the top by default. “Allow moving the island” is on by default; pulling the pill to the left or right edge docks it there as a vertical pill. With multiple monitors it follows the screen under your cursor. All of this lives in Appearance.

2Task board

The Task board in Settings lists the tasks that are running, per Agent. It only mirrors what each Agent reports; it never judges on its own.

Claude Code Rebuild the settings navigation Waiting for you
Gemini CLI Add unit tests Compacting context

Each row is a running task: status dot, Agent name, task title, current state. An illustration.

  • Each row shows the Agent name, task title, current state, and how long it has been running. Session ID, tokens used, and subtask count sit behind Details.
  • There are three states: working, waiting for you, and compacting context. Subtasks inside a session are not counted twice.
  • How to use it: Refresh in the top-right reads again immediately. When nothing is running it says nothing is running, and a row appears as soon as an Agent starts working.
  • For the full picture: the task cards on the island show the same state; click a task there to bring its window to the front.

3Usage

Usage shows how much each tool has left and how much it used recently. It only counts; it changes nothing.

Numbers are illustrative; quota, tokens, or prices that cannot be read show Unknown instead of 0.

  • “How much is left”: remaining quota, reset time, last update, and state for each tool. Unreadable values show Unknown.
  • “Usage & cost”: tokens used today, this week, and this month, with input, output, and request counts, expandable per model. Opening the page scans local session logs in the background.
  • Amounts are estimates: they come from local session records and a built-in price table, for reference only. Models without a public price show token usage only, with no amount.
  • Online checks are off by default: allow them one tool at a time with “Allow query”. Before enabling, Vibe Board explains which address it will call, or which local program it runs, and which login information it uses (file location only, never the value). You can turn it off at any time.
  • “Show quota on the island” only controls the quota bar at the top of the island; it is separate from online checks. Local session records need no authorization and keep being counted.
Anything unreadable stays Unknown; Vibe Board never fills the gap with 0 or a guess.

4Skill

Skill holds the Skills you collect: see which Agents are using each one, and turn it on, update it, or delete it.

CustomImported or hand-written locally GitHubRemote updates can be checked Synced from AgentAdopted from an Agent directory
opencode-agent → Claude Code
opencode-agent → Codex

Three source categories; “active in” reflects real installs, not an exclusive binding.

  • What a Skill is: a set of instructions for an Agent. Once an Agent has it, the Agent follows it for related tasks.
  • Three sources: Custom (imported from a folder or archive), GitHub (a remote repository recorded in the source file, so updates can be checked), and Synced from Agent (adopted from an Agent's directory).
  • How to put a Skill to work: center-library Skills are inactive by default. Select one and choose which Agents should use it. “Active in” on a card is a real install record. An Agent that reads the shared folder (~/.agents/skills) and already has the Skill shows “active through the shared folder” without an extra copy.
  • When something is off: problems such as broken links show up as notices on the Skill library page; follow them to tidy things up.

5Handoff

Handoff draws a tree: who can hand tasks to whom. Once it is set up, your main Agent hands off directly and Vibe Board is not in the loop.

An illustration: every line under a main Agent is a worker it can hand tasks to.

  • Install first: the handoff tool is not bundled with Vibe Board. The page offers the install the first time; after you confirm it downloads hyNous/agent-dispatch from GitHub into ~/.agents/skills. One install is enough, and it keeps working without Vibe Board.
  • How to read the tree: the top level lists main Agents, and under each one are the workers it can hand tasks to. When a worker lives in the shared folder (~/.agents/skills), every Agent that reads it (Codex or OpenCode, for example) shows “Shared with …”; with no line, the page says that Agent has no worker yet.
  • How to connect: under an Agent click “＋ Add worker”, pick a worker, and confirm “Let X hand tasks to Y” to write the needed files. Adding again stays idempotent.
  • How to undo: click “Disconnect” and confirm to remove that worker's content. When the worker lives in a shared folder, the page lists the other Agents reading it that are affected too. Files you edited yourself are kept, with the reason shown.
  • The rules are yours to write: this page only writes the files handoff needs. It never writes your global instruction files and never writes the rules for you. Put when and to whom to hand off into your Agent's global instructions; a copyable example is at the bottom of the page.
  • Other tools: for workers outside the list, run external-agent-setup inside your Agent. If Node.js is missing, the page says so and adding or installing is disabled.

6Appearance

Appearance decides how the island looks, where it sits, and when it shows. Changes apply right away.

  • Look: choose between “Midnight black” and “Frosted glass”. When idle only the icon stays; while working only the Agent name shows.
  • Position: centered at the top by default. “Allow moving the island” is on by default; drag it to move it, and drag it to the left or right edge to dock it as a vertical pill.
  • Monitor: it follows the screen under your cursor by default, or you can pin it to one screen.
  • Size and behavior: expanded panel width, font size, refresh rate, hiding when there are no sessions, and more. “When closing the window” chooses between the tray and quitting.
  • If it gets messy: “Restore island defaults” brings back the original look.

7Shortcuts

Shortcuts gives common actions a key combination, so you can use the island without the mouse.

  • Global shortcuts (work anywhere): Ctrl/Cmd+Shift+I shows or hides the island, and Ctrl/Cmd+, opens Settings by default.
  • Shortcuts inside the panel: Esc collapses the panel step by step, and Ctrl/Cmd+J jumps to the active task's terminal window. Expand, collapse, and previous / next session can each get their own key.
  • How to change one: click the field and press the combination you want. If it is taken, Vibe Board says which action uses it.
  • To turn one off: Clear removes a combination. Combinations you leave empty read “Not set”.

8General

General holds the everyday switches: interface language, starting with your computer, which Agents are connected, and quitting.

  • Language: switch between Chinese and English; it applies right away.
  • Open at login: off by default. Turn it on and Vibe Board starts when you log in.
  • Connected Agents: click “Choose Agents” to walk through the wizard again. This row also shows how many Agents open the board when a session starts; with none connected it says no Agent is connected yet.
  • Quit: use “Quit” when you want to shut the app down completely.

10About

About shows the version, updates, and feedback links, and builds a diagnostics bundle for troubleshooting.

  • Updates: check manually, or turn on “Check for updates automatically” and “Install updates automatically”. When a new version is ready, Vibe Board asks you to restart.
  • Feedback: Releases and Report a bug open the matching GitHub pages.
  • Export diagnostics: builds an archive with sensitive information redacted first, ready to attach to a report.
  • Version: only the name shows by default; open “Version details” to see the exact version.
