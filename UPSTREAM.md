# Upstream and provenance

Vibe Board is a modified distribution of [AgentBro](https://github.com/shirenchuang/agentbro).

- The upstream source code is published under the Apache License 2.0.
- This fork keeps the upstream `LICENSE`, `NOTICE`, and trademark guidance.
- AgentBro names, logos, icons, website visuals, and other brand assets are not reused as the product identity.
- Vibe Board changes are maintained in this repository and are not presented as official AgentBro releases.
